# 🍅 Pomodoro Timer

A simple Pomodoro Timer application built using Python and Tkinter.

## 📌 Features

- 25-minute work timer
- Short and long break sessions
- Automatic session switching
- Reset functionality
- Visual progress tracking with checkmarks
- Simple and clean UI

## 🛠️ Technologies Used

- Python
- Tkinter
